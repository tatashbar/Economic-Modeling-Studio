# Rules: Documentation

- Use the templates in `docs/templates/`
- Every number traces to a model run, source or code reference
- Every chart and table traces to saved code: a model run, or a script saved next to it that reads saved run outputs (never a chart drawn only in the session)
- Keep notation consistent with the model spec
- State limitations and non-uses in the main text
