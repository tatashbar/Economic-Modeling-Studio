# Rules: DSGE Code

- Provide steady-state computation and report residuals before solving
- Report determinacy (Blanchard-Kahn) and solution order
- Report Euler-equation or other accuracy errors for non-linear solutions
- Priors are documented with rationale; prior predictive checks are stored
- Estimation scripts record chains, seeds and convergence diagnostics
